CLASSFLOW PROJECT FILES

Dashboard:
- Open index.html in Chrome or use VS Code Live Server.
- CSS is in css/style.css.
- JavaScript is in js/app.js.
- Sample data and templates are in data/.

Python analysis:
- analyze.py is the original analysis script. It uses numpy, pandas, and scikit-learn.
- Install dependencies with: python -m pip install numpy pandas scikit-learn openpyxl
- Note: the original script writes generated files to a ../data folder relative to its current working directory. Run it from a folder setup that has that output directory, or update those output paths before running it independently.

The dashboard and original project files are included; the HTML file uses css/style.css and js/app.js paths to match this folder structure.
